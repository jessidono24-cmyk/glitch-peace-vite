# REALM_SPECS

Repo drop-in: `REALM_SPECS.md`

This file is designed as a **single source of truth** for realm design sheets + hub layouts.

Sources used: `dreamscape meditation.docx` (moon-phase realm mapping + archetypes/guides) and `godform library and creature code.docx` (Godform Library + Creature Index legend + creature classes).

## Quick canonical premises

- **Default start/end hub:** Lake Realm (New Moon + Waning Crescent).

- **One main mode:** Mooncycle Run (realms keyed to phases). Other “modes” become mini-games embedded in realms.

- **Godforms:** simulation-only UI deck (buttons, not beliefs). Balance rules: OS outranks Interface; audit outranks excitement; Hearth closes loops.
