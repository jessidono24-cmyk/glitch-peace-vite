## How to Add New Research

1. Place file in the appropriate subdirectory (`psychology/`, `neuroscience/`, `biology/`, `philosophy/`, or `synthesis/`)
2. Add entry to this INDEX.md
3. Add relevant mechanics to `MECHANIC_MAP.md`
4. Update `GAPS.md` (close the gap if filling one; add new gaps discovered)
5. Add cross-references in the new file to related research and game mechanic source files
6. Include a **Falsifiability** section: how would we know if the mechanic correctly implements the research?
