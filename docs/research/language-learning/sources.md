# Language Learning Research Sources

## Sources (minimum 10)

### [Krashen, 1982] — Principles and Practice in Second Language Acquisition
**Full citation:** Krashen, S.D. (1982). *Principles and Practice in Second Language Acquisition*. Pergamon Press.
**Key finding:** Language is *acquired* (implicit, unconscious) rather than *learned* (explicit, conscious) when comprehensible input slightly above current competence level is provided (i+1).
**Game mechanic:** Language Learning mode — comprehensible input difficulty scaling.
**Application:** Vocabulary and grammar challenges are calibrated to i+1 (one step above player's demonstrated level), never presenting items too far ahead — directly implementing Krashen's input hypothesis.

### [Ebbinghaus, 1885] — Memory: A Contribution to Experimental Psychology
**Full citation:** Ebbinghaus, H. (1885). *Über das Gedächtnis* [Memory: A Contribution to Experimental Psychology]. Duncker & Humblot. (Trans. 1913, Teachers College Press.)
**Key finding:** Memory decays on a predictable exponential forgetting curve; review at the moment of forgetting (spaced repetition) rebuilds the memory trace most efficiently.
**Game mechanic:** Language Learning mode — spaced repetition scheduling.
**Application:** Vocabulary items are queued using the SM-2 spaced repetition algorithm (Leitner intervals) derived from Ebbinghaus's forgetting curve, ensuring review is perfectly timed for maximal retention.

### [Vygotsky, 1978] — Mind in Society
**Full citation:** Vygotsky, L.S. (1978). *Mind in Society: The Development of Higher Psychological Processes*. Harvard University Press.
**Key finding:** Learning occurs most efficiently within the Zone of Proximal Development (ZPD) — the gap between what a learner can do independently and with guidance; scaffolding bridges the ZPD.
**Game mechanic:** Language Learning mode — scaffolding hints.
**Application:** When a player struggles (three consecutive errors), a scaffold hint appears — partial translation, cognate highlight, contextual image — modeling Vygotsky's ZPD support, then removed as competence grows.

### [Nation, 2001] — Learning Vocabulary in Another Language
**Full citation:** Nation, I.S.P. (2001). *Learning Vocabulary in Another Language*. Cambridge University Press.
**Key finding:** Productive mastery of the 3,000 most frequent words covers ~95% of spoken text; learning high-frequency words first produces the steepest practical gain curve.
**Game mechanic:** Language Learning mode — frequency-weighted vocabulary unlock sequence.
**Application:** Words unlock in frequency order (the top 3,000 per language); completing frequency tier 1 (500 words) unlocks new dreamscapes, rewarding the practical competence Nation demonstrates is most valuable.

### [Dörnyei, 2001] — Motivational Strategies in the Language Classroom
**Full citation:** Dörnyei, Z. (2001). *Motivational Strategies in the Language Classroom*. Cambridge University Press.
**Key finding:** L2 motivational self-system is driven by Ideal L2 Self (vision of fluent future self); making this vision vivid and concrete sustains motivation through difficulty.
**Game mechanic:** Language Learning mode — ideal future-self language avatar.
**Application:** Players create a "linguistic future self" avatar (a character who speaks the target language fluently in a specific context); this avatar is shown in completion animations, concretizing Dörnyei's Ideal L2 Self.

### [DeKeyser, 2007] — Practice in a Second Language
**Full citation:** DeKeyser, R.M. (Ed.) (2007). *Practice in a Second Language: Perspectives from Applied Linguistics and Cognitive Psychology*. Cambridge University Press.
**Key finding:** Skill acquisition in L2 follows the same Fitts-Posner stages as other skills; proceduralization through deliberate practice is necessary for automatization.
**Game mechanic:** Language Learning mode — drill-to-automaticity arc.
**Application:** Each grammar structure is first practiced in controlled drills (procedural stage), then in communicative tasks (automatization stage), following DeKeyser's documented skill-acquisition sequence.

### [Lozanov, 1978] — Suggestology and Outlines of Suggestopedy
**Full citation:** Lozanov, G. (1978). *Suggestology and Outlines of Suggestopedy*. Gordon and Breach.
**Key finding:** Relaxed alertness (alpha brainwave state) dramatically accelerates vocabulary acquisition; pairing new vocabulary with baroque music at 60bpm facilitates retention.
**Game mechanic:** Language Learning mode — ambient music layer.
**Application:** The Language Learning mode uses a 60bpm ambient music track during vocabulary exposure, operationalizing Lozanov's suggestopedic immersion principle to maintain relaxed-alert learning state.

### [Baddeley & Hitch, 1974] — Working Memory
**Full citation:** Baddeley, A., & Hitch, G. (1974). Working memory. In G. Bower (Ed.), *The Psychology of Learning and Motivation* (Vol. 8, pp. 47–89). Academic Press.
**Key finding:** Working memory has separate subsystems (phonological loop, visuospatial sketchpad, central executive); language learning uses primarily the phonological loop, which has limited capacity (~2 seconds of speech).
**Game mechanic:** Language Learning mode — audio-visual dual coding.
**Application:** Vocabulary is always presented with both audio (activating phonological loop) and image (activating visuospatial sketchpad) simultaneously, distributing load across working-memory subsystems and reducing interference per Baddeley's model.

### [Ellis, 2003] — Task-Based Language Learning and Teaching
**Full citation:** Ellis, R. (2003). *Task-Based Language Learning and Teaching*. Oxford University Press.
**Key finding:** Communicative tasks that require learners to use target language to solve real problems produce deeper acquisition than form-focused exercises alone.
**Game mechanic:** Language Learning mode — in-game communicative tasks.
**Application:** Higher Language Learning levels require players to use target language vocabulary to navigate real dreamscape tasks (ask a dreamscape NPC for directions, read a warning sign), simulating the authentic communicative use Ellis shows deepens acquisition.

### [Swain, 1985] — Communicative Competence: Some Roles of Comprehensible Output
**Full citation:** Swain, M. (1985). Communicative competence: Some roles of comprehensible input and output in its development. In S. Gass & C. Madden (Eds.), *Input in Second Language Acquisition* (pp. 235–253). Newbury House.
**Key finding:** Comprehensible *output* (producing language just beyond automatic fluency) is necessary for acquisition; input alone is insufficient because production reveals gaps that input does not.
**Game mechanic:** Language Learning mode — production challenges.
**Application:** After receptive (recognition) trials, players produce the word/phrase in response to a meaning prompt — modeling Swain's output hypothesis and exposing the gap between recognition and production competence.
