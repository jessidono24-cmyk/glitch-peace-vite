## Key Findings

### Bioelectric Gradients as Information
1. Every living cell maintains a **transmembrane voltage** (resting potential: -20mV to -90mV)
2. Patterns of voltage across cell groups encode **positional information** — cells "know" where they are
3. Bioelectric patterns precede and **instruct** anatomical structure formation (not the reverse)
4. Levin's lab demonstrated: changing bioelectric patterns can cause organisms to grow different body plans
5. The bioelectric code is **information-rich** and largely separate from genetic code

### Pattern Formation Rules
- Bioelectric gradients spread via **gap junctions** (electrical synapses between cells)
- Gradients form spontaneously through reaction-diffusion dynamics (Turing patterns)
- Local perturbations propagate outward with **exponential decay** over distance
- **Phase transitions**: At certain thresholds, local patterns snap into coordinated global patterns
- Long-range coordination: cells millimeters apart can be functionally coupled via bioelectric relay

### Regeneration & Memory
- Planaria (flatworms) store body-plan memory in bioelectric patterns, not just DNA
- After decapitation, bioelectric "head map" drives correct head regeneration
- Disrupting bioelectric patterns during regeneration produces aberrant forms (extra heads, etc.)
- Implication: **Pattern memory is not purely genomic** — it has an electromagnetic layer

### Bioelectric Perception
- Sharks, rays, and platypuses detect prey via **electroreception** (ampullae of Lorenzini)
- Some plants respond to self-generated electrical signals after wounding
- Human skin generates measurable bioelectric signals during wound healing
- Electromagnetic field sensitivity: migratory birds use magnetoreception for navigation

### Applied Bioelectrics
- Weak applied electric fields accelerate wound healing (clinical evidence)
- Transcranial direct current stimulation (tDCS) modulates cognitive performance
- Bioelectric manipulation: one of the emerging frontiers for regenerative medicine

## Mechanic Implications for Constellation Mode

### Pattern Formation Dynamics
- Constellation connections should **not** be purely visual/random — use reaction-diffusion rules:
  1. Stars with high "activation potential" attract nearby connections
  2. Inhibitory gradient suppresses new connections within radius of existing ones
  3. Result: self-organized, spaced pattern resembling real bioelectric/biological morphogenesis
- This creates naturally beautiful patterns matching real night-sky distributions

### Phase Transitions in Pattern Recognition
- At certain threshold (e.g., 5+ stars connected): pattern "snaps" into recognizable shape
- Visual feedback: faint halo/glow at sub-threshold connections; bright coherent line at threshold
- Models the bioelectric phase transition from local gradient to coordinated global pattern
- Teaches: partial knowledge accumulates invisibly until sudden gestalt recognition

### Signal Propagation
- Activating a constellation node sends a **voltage-like pulse** along established connections
- Pulse amplitude decays with distance (exponential decay model)
- Cascades: sufficiently strong pulse can trigger connected nodes to activate (chain reaction)
- Player learns: seed one node strongly → activation propagates → pattern self-completes

### Memory & Re-activation
- Completed constellations leave a "bioelectric residue" — faint glow even when not active
- Revisiting a completed constellation re-activates it faster (memory trace, lower threshold)
- Models regenerative memory: pattern knowledge stored as lowered activation threshold

### Electroreception Mode
- Bonus layer: player can briefly activate "electroreception" (limited uses) to see bioelectric gradients
- Reveals strength/polarity of each star's field before connection
- Skilled players learn to predict which connections will form — implicit learning of gradient rules

## Falsifiability
