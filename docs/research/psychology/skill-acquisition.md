# Skill Acquisition Theory

## Sources
- Fitts, P.M. & Posner, M.I. (1967). *Human Performance*. Brooks/Cole.
- Anderson, J.R. (1982). "Acquisition of cognitive skill." *Psychological Review*, 89(4), 369-406.
- Ericsson, K.A. et al. (1993). "The role of deliberate practice in the acquisition of expert performance." *Psychological Review*, 100(3), 363-406.

## Key Findings
1. **Cognitive stage**: Slow, conscious, error-prone; requires explicit instruction and working memory
2. **Associative stage**: Errors decrease; actions begin to link; less cognitive load; patterns emerge
3. **Autonomous stage**: Fast, automatic, parallel; skills run without conscious attention
4. Progress through stages requires **deliberate practice** (focused effort at edge of ability)
5. Expert performance is not about talent but about accumulated hours of deliberate practice

## Application in GLITCH·PEACE
- Tutorial / early game = cognitive stage (explicit instruction, simplified mechanics)
- Mid game = associative stage (emerging intuition, reducing scaffolding)
- Late game / mastery = autonomous stage (flow, new challenges introduced)
- Emergence Levels 1–5 directly map to cognitive → autonomous progression
