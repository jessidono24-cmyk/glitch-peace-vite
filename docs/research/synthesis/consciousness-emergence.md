# Consciousness Emergence

## Overview
This document synthesizes research on consciousness as an emergent property, drawing on neuroscience, philosophy, systems theory, and the wisdom traditions.

## Sources

## Key Theories

### Integrated Information Theory (IIT) — Tononi
- Consciousness = phi (Φ) — the amount of integrated information in a system
- High Φ = rich conscious experience; low Φ = minimal/no consciousness
- Consciousness is not binary but a continuous spectrum
- Implication: any sufficiently integrated information-processing system may have some consciousness

### Global Workspace Theory (GWT) — Baars/Dehaene
- Consciousness arises when information is broadcast through a "global workspace" (prefrontal-parietal network)
- Most processing is unconscious; consciousness is selective illumination
- "Ignition" events: when a stimulus crosses a threshold → global broadcast → conscious experience
- Flow state may involve a sustained global workspace ignition

### Neural Correlates of Consciousness (NCC)
- Specific neural signatures reliably accompany conscious experience
- **Gamma oscillations** (40Hz) associated with conscious binding
- **P300 wave**: EEG marker of conscious access (appears ~300ms after stimulus)

### Emergence Principles
1. Consciousness emerges from sufficient complexity and integration — not added from outside
2. The "hard problem" (Chalmers): Why does any information processing feel like something?
3. Emergent properties cannot be fully predicted from component properties alone
4. Self-reference (a system modeling itself) may be necessary for higher consciousness

## Application in GLITCH·PEACE

### Emergence Levels as Consciousness Stages
- **Level 1**: Reactive (unconscious stimulus-response; IIT Φ ≈ low)
- **Level 2**: Pattern recognition (chunking; associative awareness beginning)
- **Level 3**: Strategic (explicit modeling of game state; global workspace active)
- **Level 4**: Intuitive (flow state; effortless processing; transient hypofrontality)
- **Level 5**: Integrative (cross-modal, whole-system awareness; highest Φ state)

### Glitch as Phase Transition
- "Glitch" events = consciousness ignition moments (GWT ignition)
- System running smoothly → sudden disruption → new awareness of underlying structure
- This mirrors insight experiences in meditation and therapy

### PEACE as High-Φ State
- PEACE tile collection increases system integration (multiple subsystems coordinating)
- The PEACE state models high-Φ consciousness: more aspects of experience integrated
- DESPAIR/RAGE = low-Φ fragmented state: survival mode, reduced global workspace
