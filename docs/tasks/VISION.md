## What This Game Is

GLITCH·PEACE is a consciousness-awakening engine disguised as a video game.
It is simultaneously:
- A therapeutic tool for recovery, self-awareness, and pattern recognition
- A research-grade model of consciousness emergence (replicable, falsifiable)
- A layered play experience that meets every player where they are
- A living archive of sterilized world wisdom encoded as gameplay mechanics

The game does not teach. It models. Players don't read about flow states —
they enter them. Players don't study emotional regulation — they practice it
through mechanics. The research is the skeleton. The game is the flesh.

---

## Architecture: The Four Layers

Every play session is defined by four orthogonal dimensions:

```
GAME MODE       — the physics and form of play (HOW you interact)
DREAMSCAPE      — the landscape and setting (WHERE you are)
COSMOLOGY       — the belief system overlay (WHAT LENS you see through)
PLAYSTYLE       — the emotional/energetic mood (HOW YOU FEEL while playing)
```

These four must be VISUALLY AND MECHANICALLY DISTINCT from each other.
When you combine them, the combination should feel unique:

> Grid mode + Void State + Book of Changes + Pattern Recognition
> must look and feel different from
> Grid mode + Mountain Dragon + Nine Realm Tree + Warrior

This is not cosmetic. The combinations ARE the content.

## Dreamscapes — The Landscapes

18 dreamscapes, each with:
- A distinct color palette
- Ambient audio signature
- Unique hazard/terrain types
- Emotional resonance
- Research-grounded therapeutic context

Dreamscapes are NOT just backgrounds. They modify the physics and available
mechanics of whatever mode is active within them.

Example: Void State dreamscape in Grid mode = sparse, slow, few tiles, silence.
Mountain Dragon dreamscape in Grid mode = dense, complex, guardian enemies.

---

## Cosmologies — The Belief Lenses

13 cosmologies, each representing a world tradition. They:
- Rename game elements (PEACE tiles become chakra points, or runes, or hexagrams)
- Add tradition-specific lore to popups
- Apply a color filter/atmosphere
- Unlock cosmology-specific mechanics (Norse: Yggdrasil branching paths, etc.)

Cosmologies teach through exposure. After 10 sessions with Seven Universal Laws,
the player has absorbed Hermetic principles without a single lecture.

## Research Integration Philosophy

**The game models research. It does not teach it.**

Bad approach: "This level teaches Cognitive Load Theory."
Good approach: The level IS designed with cognitive load limits —
  the player experiences reduced overwhelm without knowing why.

Bad approach: Show a popup saying "You just experienced dopamine release!"
Good approach: The reward timing IS calibrated to dopamine cycle research —
  the player feels the pull without the explanation.

**What makes it replicable and falsifiable:**
- Every mechanic maps to a specific research claim
- The research folder documents WHAT claim each mechanic models
- If the mechanic is changed, the research note must be updated
- This creates a living audit trail

**Research gaps to fill:**
- Fascia/somatic research → movement mechanics in meditation/embodiment modes
- Mycelium/network biology → mycology mode connections
- Electrostatic biology → constellation mode (bioelectric fields as pattern)
- Extremophile biology → difficulty adaptation system
- Chronobiology → temporal mechanics, planetary rhythm
- Addiction neuroscience (specific circuits) → pattern training mode
- Interpersonal neurobiology (Siegel) → relational mechanics in RPG mode

## What Playstyles Actually Are

Playstyles are MOOD MODIFIERS, not separate modes. They answer:
"How does the player want to feel during this session?"

| Playstyle | Mood | Mechanical Effect |
|-----------|------|-------------------|
| Classic Arcade | Competitive, score-focused | Faster pace, score multipliers |
| Zen Garden | Calm, unhurried | Slower enemies, ambient focus |
| Warrior | Intense, confrontational | More hazards, higher stakes |
| Sage | Contemplative, curious | More lore popups, puzzle focus |
| Healer | Restorative | More health recovery items |
| Explorer | Curious, expansive | More hidden tiles/paths |
| Pattern Training | Analytical | Pattern visibility enhanced |
| Ritual | Ceremonial | Timed breathing prompts |

Playstyles apply WITHIN the mode. They do not replace the mode.
They should be selectable from the PAUSE menu, not a pre-game screen.
This removes the overwhelm of a separate playstyle selection step
and makes them feel like real-time adjustments to the experience.

## Tutorial System

Every new element gets a contextual tooltip on first encounter.
Stored in: player save data (per slot)
Referenced via: pause menu → "Review Tutorials"

Tutorial triggers:
- First time player sees a new tile type → brief floating label
- First time a new mechanic activates → 3-second overlay
- First time entering a new mode → brief mode intro (skippable)
- First time entering a new dreamscape → dreamscape flavor text (skippable)

These ONLY appear on first encounter per save slot.
Never repeat unless player requests via pause menu.

## Menu System Clarifications

**What each option actually does:**

- **PARTICLES**: Visual particle effects (fireflies, dust, energy wisps). OFF = performance mode for slower machines.
- **SOUND**: Master audio toggle. Some players need silence.
- **MUSIC**: Background ambient music only.
- **MATRIX TOGGLE**: Switch between Matrix A (Erasure/red) and Matrix B (Coherence/green) visual mode.
- **DASHBOARD**: Opens the consciousness stats overlay mid-game.
- **EMERGENCE LEVEL**: Your consciousness progression tier (Dormant → Noticing → Awakening → Integrating → Sovereign).
- **TEMPORAL**: Time-of-day and lunar phase display in HUD (cosmological accuracy).

Any option not clearly explained in-menu gets a one-line description on hover.

## Technical Standards

- Default viewport: laptop screen (1280×720 minimum, scales up)
- Canvas always 100vw × 100vh
- No grid tiles outside Grid Navigator mode
- No playstyle selection screen (integrated to pause menu)
- Playwright timeout: unlimited (set to 3,600,000ms = 1 hour)
- All automated tests run until 0 failures before moving to next task
- Research folder: `docs/research/` — consolidate all research there
